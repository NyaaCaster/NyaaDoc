## 续接提示词

继续 NyaaDoc V1 开发时，必须以 **plan 模式**推进。先读 `.docs/开发计划-SSOT.md`（唯一事实来源）与 `.docs/设计审核.md`，不要在提示词里重复已完成事项。

当前处于 **P0 立项已完成、P1 未开始**（远端仓库已清空为 0 文件、项目级 `CLAUDE.md` 已建立）。**P1 要做的第一件事**：建立 `.gitignore`（Python/Node/Docker/`.env`/`.ref` 全覆盖）与 `meta.json`（项目元数据单一来源），然后 `docker pull docmost/docmost:0.96.0` 并**进容器核实 `/app/apps/client/dist/locales/` 与 `icons/` 是否存在**——这是解锁 P2 薄镜像的前提；随后本地 `git init`、关联远端并首次提交。

关键约束（不得违背）：V1 只做**薄镜像品牌化**（不编译前端），源码级外观改造归 V2 且**禁止预先铺开**；上游按 v0.96.0 + digest 锁定，不用 `latest`；应用端口仅绑定 `127.0.0.1`，公网只经 nginx `43083 ssl`；`APP_SECRET` ≥32 字符且只存 `.env`；自动化脚本一律 Python，禁止 `.ps1`/`.sh`；私有仓库地址禁止硬编码，只从 `.env` 的 `PRIVATE_DOCKER_REGISTRY_HOST` 注入并在输出中掩码；不提交 `.env`/`.env.*`（`.env.example` 除外）/`node_modules`/`dist`/数据库卷；保留上游 LICENSE 且显著标注"基于 Docmost 修改"；EE 目录（`apps/*/src/ee`、`packages/ee`）原样不动；核心文件保留运行时可见的代码签名 `Nyaa be with you.`；Git 逐文件 `git add`，禁 `Co-Authored-By` 与 force push，推送走 `$GITHUB_PAT`。

在执行任何容器启动或 macmini 变更前，先取得用户明确许可。
